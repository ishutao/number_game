# 数字游戏 - Digital Game

胡桃Mahero的第一个完整python项目

## 📝 项目介绍

数字游戏是一个使用Python语言开发的命令行游戏集合，提供了多种有趣的数字相关游戏模式。包含了完整的游戏流程控制、存档管理、难度设置等功能。

## 🎮 游戏模式

### 1. 猜数字
系统随机生成一个数字，玩家需要在游戏中猜中这个数字。根据不同难度级别，数字范围会有所不同
猜中数字后会根据使用的尝试次数获得相应分数奖励，并可以解锁更高级别的难度。

### 2. Boss挑战
该模式，玩家需要通过猜数字来击败各种强大的Boss敌人。每种难度对应不同的Boss
每个Boss都有独特的能力和属性，玩家需要在有限的生命值内击败它们。

### 3. 闯关挑战
最复杂的游戏模式，玩家将扮演一个角色在不同的地图中冒险
每个地图包含多个关卡和房间，玩家需要完成各种数字挑战，击败敌人，收集经验值升级，最终挑战地图Boss。

## 📋 功能特性

- **多种游戏模式**：提供三种不同风格的数字游戏
- **难度分级**：每种模式都有多个难度级别
- **存档系统**：自动保存游戏进度，支持继续游戏
- **加密存档**：使用简单加密算法保护游戏存档
- **关卡解锁**：通过完成挑战解锁新的内容
- **角色系统**：在闯关模式中拥有完整的角色属性和升级系统
- **敌人系统**：丰富的敌人类型和Boss设计

## ⚙️ 安装说明

### 环境要求
- Python 3.6 或更高版本
- 无需安装额外的第三方库，使用Python标准库开发

### 安装步骤

1. **克隆或下载项目**
   ```bash
   git clone [GitHub仓库地址]
   # 或直接下载项目压缩包并解压
   ```

2. **运行游戏**
   - Windows用户可以直接运行 `游戏启动器.bat`
   - 或者在命令行中执行：
     ```bash
     cd 数字游戏
     python mainpy\主界面.py
     ```

## 📖 使用方法

### 主菜单
游戏启动后会显示主菜单，包含以下选项：
1. 开始游戏 - 选择新游戏模式
2. 继续游戏 - 加载最近的存档
3. 游戏详情 - 查看游戏介绍
4. 存档管理 - 管理游戏存档
5. 设置菜单 - 游戏设置选项
0. 退出游戏

### 游戏控制
- 使用数字键选择菜单选项
- 在猜数字游戏中输入数字进行猜测
- 按照游戏提示进行操作

### 存档管理
在设置菜单中可以：
- 一键解锁所有关卡
- 锁定所有关卡（除第一关外）
- 查看解锁状态
- 快速管理存档
